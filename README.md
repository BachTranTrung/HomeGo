# 🏠 HomeGo — Website Bán Đồ Gia Dụng

Website thương mại điện tử bán đồ gia dụng chuyên nghiệp.

## 🛠️ Công nghệ sử dụng

| Tầng | Công nghệ |
|------|-----------|
| **Frontend** | HTML5, CSS3, Bootstrap 5, Fetch API |
| **Backend** | Node.js, Express.js, JWT, bcryptjs |
| **Database** | MongoDB, Mongoose (với Pagination server-side) |
| **Tích hợp** | Google Sign-In, VNPay, Google Maps, Dialogflow AI |

## ✨ Tính năng

- 🛍️ Mua sắm: xem sản phẩm, tìm kiếm, lọc, pagination
- 🛒 Giỏ hàng & đặt hàng với mã giảm giá
- 💳 Thanh toán COD & VNPay
- 🔐 Đăng nhập thường & Google OAuth
- 🤖 AI Chatbot (Dialogflow + fallback)
- 📍 Google Maps hiển thị showroom
- 📊 Admin: dashboard thống kê, CRUD sản phẩm, quản lý đơn hàng
- ⭐ Đánh giá & nhận xét sản phẩm

## 🚀 Chạy nhanh

```bash
# 1. Start MongoDB

# 2. Backend
cd backend && npm install && npm run seed && npm run dev

# 3. Frontend — mở bằng VS Code Live Server
# Vào http://localhost:5500
```

Xem **HUONG_DAN_CHAY.md** để có hướng dẫn đầy đủ chi tiết.
